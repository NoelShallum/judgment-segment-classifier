Judgment-role classifier stocktake

AttoFlow research pause · 22 November 2026. The product accepts English text from an Indian judgment. A sentence or paragraph gets one of seven roles. A longer upload can return the character range of each role.

The internal BERT edit is one correct answer ahead of Gemini on 196 independent judgments and one behind on the 112-sentence balanced pilot. Its 196-case accuracy difference has a paired 95% interval of -6.6 to +7.7 percentage points. Both missed more than half the human sentence labels.

The clearest repeatable gain

On all 712 raw test judgments, halving 49 role-transition weights moved exact labeled-span F1 from 0.198 to 0.257 and token accuracy from 58.9% to 60.4%. Supplied the original sentence boundaries, the edited model scored 0.567 macro-F1 against LegalSeg’s reported 0.770.

The stocktake stops at the last completed comparisons. The evidence supports a document-boundary improvement. Sentence parity with Gemini and a new research state of the art remain unestablished.

We selected one of 36 direct transition programs on exact labeled-span F1. The winner multiplied all 49 role-to-role scores by 0.50 and retained the original start and end scores. Less persistence allowed more true transitions to appear. The test comprised 1,527 recorded units from 20 cases. The 95% paired span-F1 gain interval was -1.9 to +11.7 percentage points.

For an isolated sentence or paragraph, the same architecture treats that one input as both the start and the end of a judgment. Zeroing its seven starting and seven ending weights gave the best excerpt profile among 28 programs. That edit changed 14 values. Its weighted confirmation accuracy moved from 40.5% to 46.1%.

The held-out evaluation contains 20 complete test judgments, 1527 labeled source rows and 45,943 whitespace-delimited tokens. Rejoining source rows with one ordinary space removes explicit row boundaries. PDF layout cannot be reconstructed from these CSVs.

The programmed decoder used B isolated, diagonal transition weight 0, directed-order weight 0 and neighboring-logit coefficient 0. The program wrote a 7 × 7 transition matrix and a three-value neighbor kernel. We selected among 48 prespecified combinations on ten development judgments, confirmed on ten separate judgments, then scored twenty untouched test judgments.

Exact labeled-span F1 requires the beginning, end and role to match. Boundary F1 scores interior role-change offsets without a role label. Token accuracy weights each non-whitespace token equally. The oracle row-boundary comparison isolates boundary-detection losses.

The first set contains 21 source-labeled units from 17 judgments, three per role. Each contains multiple statements. Many qualifying rows concern sums of money or contain court enumeration, which limits generalization. We screened and masked identifying details before either model saw them.

The second set contains two or three consecutive source rows from one judgment. Every constituent row has the same human role. Joining them provides a derived paragraph label. These easier, same-role passages cannot establish accuracy on mixed-role paragraphs with one adjudicated dominant label.

At inference, long submissions use 510-token BERT windows with nominal overlap 128. The final window ends at the last token. Voting weights partition the content across windows so overlaps contribute once. On all 149,881 official test rows, 18 exceed one window.

A seven-row instruction-model head

Gemma 4 E2B runs locally. Its Q8 text backbone occupies 4,967,491,520 bytes. Seven rows of width 1,536 and seven biases add 10,759 task-specific parameters.

The frozen instruction model reads the role definitions, then the user’s excerpt. At its final prompt token we take the 1,536-dimensional hidden state. Seven existing A–G vocabulary rows provide a control. Replacing the language-model output with the programmed matrix produces seven scores directly.

The written head uses content-free bias coefficient 0.25 and associative damping 1. Five content-free inputs specify the bias. Where enabled, 21 authored keys specify a closed-form correction. The search used 56 development sentences. An additional 56 sentences come from a disjoint validation fold.
