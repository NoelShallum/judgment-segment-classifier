Single-label contract

A standalone English sentence or paragraph returns one of seven classes. A full judgment or a passage with several roles can instead return a list of labeled spans. A paragraph with more than one rhetorical function can therefore be explored in span mode while the single-label interface retains the requested multiclass contract.

The compact BERT model has 512 total subword positions. With normal single-sequence encoding that leaves 510 positions for text per window. Its inference wrapper scores longer passages over overlapping windows and aggregates the scores. The 16.82M-parameter hierarchical model has no fixed BERT-style token window. It reads each candidate unit with a word-level LSTM and then the complete unit sequence with a document-level LSTM. The largest test judgment had 59,996 whitespace tokens. A new score estimates whether a whole span has the exact start, end and rhetorical role. A closed-form weight write uses 16,611 candidate spans from 144 official training judgments, with 851 exact matches. Inputs include the frozen CRF probability of the span, votes from eight proposed label sequences, the span length and position, and the model scores near the span boundaries.

The decoder chooses adjacent spans with different roles that cover the entire judgment. One candidate set takes spans directly from the eight sequences. The expanded set also moves one endpoint of a span to a neighboring cut proposed by another sequence.

Validation selected the expanded candidate set, gave the written readout 70% weight and subtracted a fixed cost of 0.24 for each span.

How the editing literature applies

Humza and Omar Nusrat audited 433- to 4,801-parameter networks with planted errors and tested each proposed repair against known rules. They reported a median of three changed parameters across successful repairs. This is direct evidence that sparse writes can fix identifiable behavior in small systems. It motivates preserving the largely intact checkpoint and checking unrelated behavior independently.

Clinical weight-space audit

Ok and Lee write sparse associative tables from examples. We give each role an authored set of representative utterances and write a seven-row readout from their activations. We compare simple role means with a regularized correction for each key.

Weight-Space Programming Doesn't Need Transformers · Associative memory code and weights

ROME writes a rank-one update in a particular MLP layer to change a factual association. MEMIT and EMMET generalize to batches of edits. The earlier final-MLP InLegalBERT trial used a related low-rank write to a pretrained projection. It helped on some sentence samples while losing weighted validation accuracy. The new encoder readout starts from class prototypes over frozen hidden states. The normalization trial changes existing pretrained coefficients and verifies those changes in an actual forward pass.

AlphaEdit and CrispEdit preserve behavior by limiting the directions an update may modify. This experiment adapts the idea by estimating activation directions from 192 unlabeled LegalSeg training excerpts. One candidate protects none of those directions. Others project the correction away from the leading 16 or 48 directions. The resulting edit is a covariance-based approximation and it supplies no general capability guarantee. CrispEdit itself uses a different curvature estimate and projected optimization.

A separate analytic residual edit estimates a correction from misclassified LegalSeg training rows and penalizes changes on rows the parent already labels correctly. This uses training annotations to fit a closed-form change to existing classifier weights. Task arithmetic edits several tensors together using differences between checkpoints that share a base. Our earlier compatible-weight interpolation lost to keeping its stronger parent.
